# مكتبة AES-128 التعليمية

تنفذ هذه المكتبة خوارزمية AES-128 بلغة بايثون دون مكتبات تشفير خارجية.
تتضمن النواة العمليات الأساسية، وجدولة المفاتيح، ووضعي ECB وCBC، مع خدمة
FastAPI تقدم واجهة مستخدم من نفس الأصل وواجهة OpenAPI تفاعلية.

## التشغيل

```bash
docker compose up --build api
```

التطبيق متاح على `http://localhost:8000` والوثائق على
`http://localhost:8000/docs`.

يجب أن يكون المفتاح 16 بايت UTF-8 بالضبط. للاستخدام الإنتاجي يُنصح باستخدام
تشفير موثق مثل AES-GCM وإدارة المفاتيح خارج التطبيق.
