# 🔐 AES-128 Educational Library - Project Brief

## 🎯 Mission
Build a production-ready, educational AES-128 encryption library in Python 
that demonstrates deep understanding of cryptography internals.

## 📦 Tech Stack
- Language: TypeScript (strict mode)
- Runtime: Node.js 18+ / Browser (via Vite)
- UI: React 18 + TailwindCSS (for demo)
- Testing: Vitest
- Hosting: Vercel

## 🚫 Constraints
- NO external crypto libraries allowed (except Web Crypto API for validation only)
- Must be constant-time safe
- Must follow OOP principles strictly
- Must include full JSDoc comments
- Must include unit tests
- Must expose both high-level API and low-level building blocks

## 📊 Success Metrics
- Encrypts and decrypts "Hello World" correctly
- Passes NIST test vectors
- Zero external dependencies
- Code coverage > 90%
- Bundle size < 15KB gzipped
